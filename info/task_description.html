Enunciado

Carlos, um analista financeiro, está revisando as transações mensais de uma empresa. Ele precisa somar todas as transações armazenadas em uma lista para obter o total de gastos ou receitas do mês.

Escreva uma função que receba uma lista de números e retorne a soma de todos os elementos usando um loop for.

Entrada: Uma lista de números inteiros.

Saída: Um número inteiro representando a soma dos números da lista.
